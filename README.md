# 基于vitepress搭建个人技术博客

## 技术栈

- **VitePress** - 静态站点生成器
- **Markdown** - 内容编写

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run docs:dev
```

访问 http://localhost:5173

### 构建生产版本

```bash
npm run docs:build
```

或直接在服务端运行`deploy.sh`脚本

### 预览构建结果

```bash
npm run docs:preview
```
