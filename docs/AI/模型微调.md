# 模型微调

## 微调的作用

众所周知，训练一个llm的成本是很高的。如果对每一个行业都训练一个模型出来，不经济不环保也不现实。

作为一个“好事之徒”，我稍微检索了一下“微调”是怎么来的。从需求上来说，一些行业并没有那么充足的数据来支撑一个完整的模型训练。算力问题可以砸钱，没数据那就是真没数据了。

然后出现了“迁移学习”的概念。用一个已经训练好的模型，来训练一个新的任务。个人理解，如果对模型的训练有基本的了解的话，应该知道本质上是一个超大规模参数的函数的拟合过程，参数的寻找类比为在一个丘陵地区上找最低点的过程，而初始的起点是随机的。那么，如果要训练一个新模型，就要从一个随机的起点来找最低点，如果是基于一个本来就很低的点，那么就可以很快找到下一个很低的点。世界上的运行规律是有相似点的。

而省钱，环保，基于预训练好的模型微调效率高，都是在解决“能不能”之后“好不好”的方面了。

## 微调的步骤

如果理解了微调的作用，很容易发现，微调模型和训练一个模型在操作过程上基本是一致的。下面的过程来源于hugging face教程。

### 数据处理

数据的格式上，模型需要什么，就要改造成什么样子。但是普遍的，都需要进行tokenizer，truncked，padding这样的操作。

### 训练

训练之前需要设置到超参数。可以简单设置一下保存模型参数的目录。其实说句题外话，给模型做微调的门槛虽然没有那么高，但是经常微调后的效果还不如不调。这还是一个比较新的行业，还在经验的积累期。

```python
from transformers import TrainingArguments
training_args = TrainingArguments("test")
```

然后就可以定义模型了：

```python
from transformers import AutoModelForSequenceClassification
model = AutoModelForSequenceClassification.from_pretrained(checkpoint, num_labels=2)
```

import进来的方法会丢弃模型的原始头，`num_labels = 2`加了一个二分类的头部。从告警的信息中可以看到丢弃的是哪些层。

现在有了数据集，有了模型，有了超参数，就可以开始训练了。可以定义一个Trainer类，来整合这三个部分。注意现在的Trainer类的`__init__`方法已经没有`tokenizer`这个形参了，需要修改成`processing_class`。

```python
from transformers import Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    data_collator=data_collator,
    tokenizer=tokenizer,
)
```

然后执行训练：

```python
trainer.train()
```

需要等待一段时间。Google的colab默认的运行时是cpu，训练时间相当的长。修改运行时为T4 GPU后，训练时间明显加速，只用4min就训完了。

### 评估

使用训练集训练完了，下面就是用验证集评估模型了。但是还需要抽象一个评估的方法出来。

```python
# 获取验证机的预测结果
predictions = trainer.predict(validation_dataset)
predictions.predictions.shape # (408,2), 有408个样本，每个样本有两个预测值，分别表示negative和positive的概率
predictions.labels.shape # (408,), 这是408个样本的真实标签，就是验证集的正确答案
```

其实到这里，自己写一个计算准确率的方法也可以。但是这种通用的步骤都是有库的：

```python
import evaluate
metric = evaluate.load("glue", "mrpc")
metric.add(predictions=predictions.predictions, references=predictions.labels)
metric.compute()
# {'accuracy': 0.85, 'f1': 0.89}
```

现在把评估的方法整合到Trainer类中。

```python
trainer=Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    data_collator=data_collator,

```

调用trainer.train()方法，重新进行训练。
