# 从零学习模型量化

## 为什么需要量化

大模型推理目前的瓶颈常常不在“算”而是在“存”。一个模型动辄几十G起步，且推理过程中的上下文也会占用大量内存。量化可以将高精度的权重参数映射为占用空间小的低精度参数。从FP32->int8，权重参数的体积就减少了75%。也就是说，量化是大模型推理时通过将高精度参数转化为低精度参数，以模型智能损失换取工程性能提升的技术。

## 量化计算过程

### 浮点数的表示

要理解量化是如何计算的，或者说量化是如何对高精度的数进行缩放的，就必须要明白浮点数是如何表示的。

对于32位的单精度浮点数，有1位的符号位，8位的指数位，23位的尾数位；

对于64位的双精度浮点数，有1位的符号位，11位的指数位，52位的尾数位；

但是计算方式不是简单的：符号位 \* 2^指数位 \* (1+尾数位)。指数部分采用了 **The Biased exponent（有偏指数）**。IEEE754 规定，2ᵉ⁻¹-1 的值是 0，其中 e 表示指数部分的位数，小于这个值表示负数，大于这个值表示正数。因此，对于单精度浮点数而言， 2⁸⁻¹-1 = 127 是 0；双精度浮点数，2¹¹⁻¹-1 = 1023 是 0。举例来说，如果指数是-3，指数位是127-3=124.

计算最大的浮点数：尾数位都为1的情况下，小数点后23个1，那么值为1-2^(-23)，指数位全为1，是2^8，实际的指数是127，那么能表示的最大浮点数是(2-2^(-23))\*2^127，约为2\*128；
计算最小的浮点数：尾数位都为0，指数位均为0，指数位-127，但是-127有特殊含义，所以指数位最小为-126，那么能表示的最小浮点数为1\*2^(-126);

注意上面的计算方式仅基于上面提到的前提，实际上还有非规格化数的规定，但是我觉得了解到这里对于理解量化基本已经可以了。

### 对称量化

量化前后，值域都是以0对称的。

一种经典方法是用量化前的最大绝对值作为int8的最大值，这种映射会得到一个缩放系数S，其余的参数按照这个参数进行缩放即可。

### 非对称量化

非对称量化并不以0中心对称。它将浮点数范围中的最小值（β）和最大值（α）映射到量化范围（quantized range）的最小值和最大值。

这个方法的缩放系数 S=256/(α-β), 但是仅有缩放系数，只是把原本的方位缩放到了一个256之内的范围，还需要一个偏移值移动到[-128,127]的区间内。

偏移值基于最小值β，Z=-128-round(β\*S). 那么其他参数就可以进行映射 Xq=round(S\*X)+Z
